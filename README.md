# Credential Usage Confidence Scoring System

A **Java-based Credential Usage Confidence Scoring System** developed as a **Semester 2 Team Project**.

## Project Overview

This project analyzes credential usage patterns and classifies confidence/risk levels using Java-based logic and scoring mechanisms. It helps in evaluating user credential behavior and determining appropriate actions based on confidence scores.

## Features

* Credential risk classification
* Confidence score calculation
* Rule-based action handling
* Test case validation
* System flow and architecture diagrams

## Technologies Used

* Java
* Risk Classification Logic
* Confidence Scoring Mechanism
* Rule-Based Action Engine

1. Install Java on your computer
2. Download the repository

4. Run the required Java classes to test the scoring and classification logic
